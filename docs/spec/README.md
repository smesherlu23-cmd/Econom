## Соглашения

- Язык документов — русский, идентификаторы в коде и данных — английские (`snake_case`).
- Знак в матрицах: `+` — актив (или приток), `−` — обязательство (или отток).
- Деньги в коде хранятся целыми числами в минимальных единицах валюты (копейках), не числами с плавающей точкой.
- Каждый параметр модели получает идентификатор, единицу измерения, диапазон и значение по умолчанию.
