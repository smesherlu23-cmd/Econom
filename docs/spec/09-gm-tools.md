## 1. Главный принцип: шок по первопричине (ядро)

ГМ меняет **причины**: параметры, правила, состояние агентов и мировые рынки. **Результаты** (ВВП, инфляцию, безработицу)
считает статбюро по сделкам агентов (раздел 06), и задать их напрямую нельзя.

Пример. Записать «ВВП −3%» нельзя. Можно записать «экспортёры нефти из ИИ-стран добывают на 7,5% мировой добычи меньше».
Тогда цена нефти, издержки фирм, курс, инфляция и спад возникают сами, а игроки могут найти причину и смягчить удар.
Исход не задан заранее: подготовленная страна переживёт тот же шок легче.

Все инструменты ГМ сводятся к трём действиям:

- **правка данных** — постоянное изменение значения, формулы или переключателя (раздел 07, п. 8);
- **шок** — временная правка с силой, сроком и формой (п. 2);
- **разовая операция** — изменение балансов через базовые операции раздела 01, п. 6 (п. 4).

Остальное собирает эти действия вместе:

| Инструмент | Что это | Пункт |
| --- | --- | --- |
| Шок и бонус | временная правка параметра, правила или переключателя | 2, 3 |
| Разовая операция | разрушение капитала, заморозка активов, списание долга, деньги из остального мира | 4 |
| Шаблон | готовый набор шоков, операций и новостей с общей ручкой силы | 5 |
| Событие | шаблон, который срабатывает сам по условию | 6 |
| Новость | единственный способ сказать игрокам о действиях ГМ | 7 |
| Решения за ИИ-участников | ИИ-страны, международный кредитор, рейтинг, мировые рынки | 8 |
| Действия с приказами игроков | отклонить, отложить, открыто сменить рычаг | 9 |
| Радар рисков и пробный прогон | что ГМ видит заранее | 10 |
| Скрытые цели и туман войны | чего добиваются игроки и сколько они видят | 11 |
| История страны | шоки в разгоне до старта партии | 12 |
| Сценарии кризисов | готовые наборы для исторических кризисов и тестов раздела 10 | 13 |

## 2. Шок (ядро)

### 2.1. Запись

```yaml
shock: miners_strike
reason: "забастовка шахтёров"            # для журнала ГМ
target: A_shock                          # параметр, слот формулы или переключатель (раздел 07)
scope: {country: north, industry: coal}  # уровень из раздела 07, п. 3
op: mul                                  # mul / add / set / formula
size: -0.4                               # для mul: −0,4 значит −40%
shape: step                              # pulse / step / decay / ramp / permanent
start: 2031-03                           # дата, номер тика или next_tick
duration: 2                              # тики
```

- `op: mul` умножает значение, `add` прибавляет, `set` заменяет, `formula` заменяет формулу слота (раздел 07, п. 5.1) на срок шока.
- `size` может быть формулой. Она вычисляется один раз, в момент начала шока: например, `rand_normal(-0.3, 0.05)` берёт
  случайную силу из потока ГМ (раздел 02, п. 7).

### 2.2. Формы

`g(τ)` — доля силы, которая действует через `τ` тиков после начала.

| Форма | `g(τ)` | Пример |
| --- | --- | --- |
| `pulse` — разово | 1 при `τ = 0`, потом 0 | слух о банке на один тик |
| `step` — ступенька | 1 при `0 ≤ τ < duration`, потом 0 | забастовка на 2 месяца |
| `decay` — затухание | `0,5^(τ / half_life)`; шок снимается, когда `g < shock_epsilon` | неопределённость после политического кризиса |
| `ramp` — нарастание | `min(1, (τ + 1) / ramp_ticks)` до конца срока | ослабление стандартов ипотеки за 2–3 года до кризиса |
| `permanent` — постоянно | 1 всегда | потеря экспортного рынка |

- Формы можно соединять подряд: ступенька на 5 тиков, потом затухание с полупериодом 6 тиков. Так выглядит эмбарго, после
  которого добыча возвращается постепенно.
- Операции `set` и `formula` совместимы только с формами `pulse`, `step` и `permanent`: заменить значение «наполовину» нельзя.
- Своя таблица значений по тикам (`custom`) — v1.
- Постоянный шок по смыслу совпадает с правкой ГМ из раздела 07, п. 8. Отдельная форма нужна, чтобы все действия ГМ были
  видны в одной панели.

### 2.3. Как считается действующее значение

```
mul:  x_t = x_база,t · Π_k (1 + size_k · g_k(t))
add:  x_t = x_база,t + Σ_k size_k · g_k(t)
set:  x_t = size последнего начатого шока, пока его g > 0
затем x_t обрезается по range; вне zone ГМ получает предупреждение (раздел 07, п. 4)
```

- `x_база,t` — значение без шоков. Его по-прежнему меняют приказы игроков, правки ГМ и календарь. Шок ложится поверх базы
  и не затирает её. Когда шок кончается, значение возвращается к текущей базе, а не к тому, что было в момент начала шока.
- Если на одно значение действуют `mul` и `add`, сначала применяются все `mul`, потом все `add`. Несколько `set` на одно
  значение — предупреждение ГМ.
- **Шок по распределению** (раздел 07, п. 3) действует на собственное значение каждого агента. Разнородность сохраняется,
  а после конца шока ничего не нужно пересчитывать.
- **Шок по переменной состояния** (доверие к ЦБ `ω`, ожидания агентов, доверие к статистике `stat_cred`) — разовое
  изменение. Оно проводится в момент начала шока, а дальше переменная меняется по своему правилу из разделов 03 и 06.
  Поэтому у таких целей только форма `pulse`: например, «давление на ЦБ» сразу снижает `ω`, а потом доверие
  восстанавливается так же медленно, как после любого другого удара.
- **Сила в понятных единицах.** Шаблон может задать силу в единицах результата: долю мировой добычи, пункты премии за риск.
  В момент начала шока движок один раз переводит её в изменение параметра по текущему состоянию. Например, «премия
  по госдолгу +2 п.п.» становится сдвигом `b_0` в оценке риска дефолта (раздел 05, п. 13.2). Дальше параметр
  не подгоняется, и настоящая премия может уйти дальше, если экономика ухудшится.

### 2.4. Что можно шоковать

| Группа | Цели | Раздел |
| --- | --- | --- |
| Производство | `A_shock` по отрасли и региону; погода `weather`; пропускная способность объекта инфраструктуры; сроки поставки; фронтир, уровень `T`, годы появления рецептов | 04, пп. 3, 5, 6, 8, 11 |
| Спрос и настроения | целевой запас домохозяйств `b_months`; доли корзины `β` (запрет услуг, мода); неопределённость фирм `uncert_gm` | 03, пп. 3.3, 3.4, 4.5 |
| Финансы | слух о банке `news_b`; мировой аппетит к риску `global_risk_appetite`; доверие к ЦБ `ω`; стандарты кредита `pd_max_base` и маржа `m_loan`; `b_0` в оценке риска дефолта | 03, пп. 3.8, 5.3, 7.3, 10; 05, п. 13.2 |
| Мир | добыча и спрос ИИ-стран на сырьё; выпуск ИИ-страны; пошлины ИИ-стран; санкции и блокада по стране и товару | 03, п. 10; 05, пп. 3.4, 4 |
| Труд и население | предложение труда (мобилизация, болезнь); переговорная сила профсоюза; миграция и смертность | 03, пп. 3.6, 3.11, 4.4; 04, п. 13 |
| Государство и институты | качество судов, коррупция, сроки разрешений на стройку и сметы госпроектов, вероятность налоговой проверки | 03, пп. 3.10, 8.6; 04, п. 10 |
| Группировки (v1) | война группировок, рост дани `pizzo` | 03, п. 9 |
| Правила | любой переключатель класса `live` и любой слот формулы на срок | 07, пп. 5, 6 |
| Статбюро | точность выборок и доля полученных отчётов (не бюджет, его меняет игрок, и не сами цифры) | 06, пп. 5, 10 |

`uncert_gm` — слагаемое ГМ в неопределённости фирм из правила инвестиций (раздел 03, п. 4.5), по умолчанию 0.

**Чего шоком менять нельзя:**

- **Рычаги игроков** (раздел 07, п. 7). Решение игрока меняет только игрок. С приказами ГМ действует открыто (п. 9).
- **Результаты статистики.** ВВП и инфляцию считает статбюро. Искажать официальные цифры может только правительство
  (раздел 06, п. 6). ГМ может открыть игрокам истинную цифру новостью (п. 7).
- **Балансы напрямую.** Только разовыми операциями (п. 4), чтобы бухгалтерия сходилась.
- **Переключатели класса `setup`.** Переключатели класса `turn` — только со сроком, который начинается и кончается
  на границе хода (раздел 07, п. 6.1).

### 2.5. Когда шок действует

- Действующие значения считаются на шаге 0 каждого тика (раздел 02, п. 5). Шок с датой внутри хода начинается в указанный тик.
- **Порядок внутри шага 0** (уточняет раздел 02, п. 5): календарь → правки ГМ, начало и конец шоков, разовые операции →
  действия ГМ с приказами (п. 9) → приказы игроков → постоянные распоряжения → демография.
- Журнал партии хранит запись шока целиком. По ней действующее значение в любом тике восстанавливается точно, поэтому
  повтор из снимка даёт тот же результат (раздел 07, п. 8).
- Откат к снимку отменяет и шоки, начатые после него.

## 3. Бонус (ядро)

Бонус — тот же шок с другим знаком. Отдельного механизма нет. В библиотеке шаблон помечен как бонус, чтобы ГМ было
проще искать.

| Событие в ролевой части | Что меняет бонус |
| --- | --- |
| Торговое соглашение с ИИ-страной | пошлины этой ИИ-страны → 0, сроки и стоимость перевозки −10% |
| Реформа, внушающая доверие инвесторам | `b_0` в оценке риска дефолта вниз (по умолчанию премия −1 п.п.), `uncert_gm` вниз |
| Открытие месторождения | запасы месторождения (раздел 04, п. 9) |
| Технологический прорыв | уровень страны `T` или фронтир отрасли (раздел 04, п. 5) |

Соглашение со страной другого игрока — не бонус: каждый игрок сам меняет свои пошлины приказом.

## 4. Разовые операции (ядро)

Разовая операция меняет балансы один раз. Она проводится базовыми операциями раздела 01, п. 6 с парной записью у второй
стороны, как ручная доводка в конструкторе (раздел 08, п. 7). Поэтому все проверки раздела 01, п. 10 выполняются и после
вмешательства ГМ.

| Операция | Как проводится | Пример |
| --- | --- | --- |
| Разрушение капитала, запасов, жилья, инфраструктуры | `real_change` у владельца: актив и чистая стоимость падают; если имущество застраховано, платит страховщик (v1) | землетрясение, война |
| Заморозка активов за рубежом | актив остаётся на балансе с признаком `frozen`: им нельзя платить и его нельзя продать; позже ГМ размораживает его или списывает `write_off` | санкции против резервов ЦБ |
| Списание долга | `write_off` пары: кредитор теряет, должник выигрывает | прощение долга ИИ-страной; «дыра» в балансе банка, где кредиты выданы подставным фирмам |
| Деньги из остального мира | `transfer` от `ROW`; в платёжном балансе это трансферт | грант, гуманитарная помощь, переводы диаспоры |
| Население | смерти, эмиграция и беженцы по когортам (раздел 03, п. 3.11); эмигранты увозят часть сбережений `transfer` в `ROW` | война, эпидемия |

Создать деньги без второй стороны ГМ не может. Если нужен «подарок», его источник — остальной мир или государство.

## 5. Шаблоны (ядро)

### 5.1. Запись

Шаблон собирает шоки, разовые операции и новости в одно действие с общей ручкой силы. ГМ запускает его одной кнопкой
и задаёт только ручки.

```yaml
template: oil_embargo
name: {ru: "Нефтяное эмбарго", en: "Oil embargo"}
kind: shock                               # shock / bonus
knobs:
  strength: {default: 1, range: [0.25, 3]}
  embargo_group: {default: opec_like}     # какие ИИ-страны сокращают добычу
  targets: {default: []}                  # против каких стран эмбарго
parts:
  - shock:
      target: ai_supply                   # добыча ИИ-стран (раздел 05, п. 4)
      scope: {good: crude_oil, countries: embargo_group}
      op: mul
      size: {value: "-0.075 * strength", unit: world_supply_share}   # −7,5% мировой добычи, как в 1973 году
      shape: step
      duration: 5
      then: {shape: decay, half_life: 6}
  - shock:
      target: export_ban
      scope: {good: crude_oil, from: embargo_group, to: targets}
      op: set
      size: true
      shape: step
      duration: 5
  - shock: {target: uncert_gm, scope: world, op: add, size: "0.02 * strength", shape: decay, half_life: 6}
  - news: {audience: all, when: start, text: {ru: "Экспортёры нефти объявили о сокращении добычи и эмбарго"}}
```

### 5.2. Библиотека для эпохи 2000–сейчас

Числа — значения по умолчанию, их меняет ГМ. Ориентир силы — то, что было в истории. Если ориентира нет, силу подбирает ГМ
и проверяет пробным прогоном (п. 10.2).

| Шаблон | Вид | Что меняет | Ориентир силы |
| --- | --- | --- | --- |
| Нефтяное эмбарго | шок | добыча ИИ-экспортёров, запрет поставок странам-целям, неопределённость фирм | выпадение 7,5% мировой добычи в 1973 году, 7% в 1978 году, около 6% в 1980 году (Hamilton 2011) |
| Внезапная остановка капитала | шок | `global_risk_appetite` вниз с затуханием, мировые цены экспорта страны вниз | в пяти странах Азии частный капитал развернулся с притока 93 млрд долларов в 1996 году к оттоку около 12 млрд в 1997 году, около 11% ВВП (Radelet, Sachs 1998) |
| Пандемия | шок | запрет контактных услуг (доли корзины `β` и `A_shock` в отраслях), болезнь работников, сроки поставки импорта, запас домохозяйств `b_months` вверх | первые шоки спроса и предложения в США затронули около 22% ВВП и 24% рабочих мест (del Rio-Chanona et al. 2020) |
| Санкции | шок | запрет экспорта технологий в страну и импорта из неё, заморозка резервов ЦБ за рубежом (п. 4), запрет потоков капитала, издержки платежей | — |
| Война | шок | разрушение капитала и инфраструктуры в регионах (п. 4), мобилизация, беженцы, `uncert_gm` и `b_0` вверх | — |
| Засуха | шок | `weather` в регионах на сезон (раздел 04, п. 8) | — |
| Забастовка | шок | `A_shock` отрасли на срок, переговорная сила профсоюза | концепция: выпуск −40% на 2 тика |
| Слух о банке | шок | `news_b` банка, разово или с затуханием | — |
| Политический кризис | шок | `b_0` в оценке риска дефолта, `uncert_gm`; отток капитала возникает сам из роста премии | концепция: премия по госдолгу +2 п.п. |
| Коррупционный скандал | шок | сроки разрешений на стройку, сметы госпроектов | концепция: сроки ×2, сметы +15% |
| Массовые протесты | шок | `b_months` вверх, `A_shock` торговли и услуг в столице | — |
| Давление на ЦБ | шок | доверие к ЦБ `ω` вниз (раздел 03, п. 7.3) | — |
| Авария на объекте инфраструктуры | шок | пропускная способность объекта → 0 на срок ремонта (раздел 04, п. 11) | — |
| Торговое соглашение, реформа, месторождение, прорыв | бонус | п. 3 | концепция |

Шаблоны других эпох лежат в их пакетах (раздел 07, п. 9), моддеры добавляют свои.

## 6. События (ядро — простые, v1 — цепочки)

Событие — шаблон, который срабатывает сам, когда выполнено условие. Так ГМ заранее закладывает реакцию мира, которую
иначе отыгрывал бы вручную, и не обязан следить за каждым тиком в асинхронной партии.

```yaml
event: protests_on_income_fall
when: "real_income_yoy_official < -0.05 and unemployment_official > 0.10"
check: each_tick                # each_tick / on_release (в тики публикации) / yearly
chance: 0.2                     # вероятность за тик, пока условие выполнено
cooldown: 12                    # не чаще раза в 12 тиков; once: true — один раз за партию
mode: ask_gm                    # auto — срабатывает само; ask_gm — ждёт решения ГМ
do:
  - template: {id: mass_protests, strength: 1}
  - news: {audience: all, text: {ru: "В столице начались протесты против падения доходов"}}
```

- **Когда проверяется.** Условие проверяется после шага 13, по данным закрытого тика. Действия начинаются с шага 0
  следующего тика, как правки ГМ (раздел 07, п. 8).
- **Вероятность.** При `chance = 0,2` среднее время ожидания — 5 тиков, как «среднее время до события» в стратегиях Paradox.
  Случайность берётся из потока `gm_events` (раздел 02, п. 7), поэтому новое событие не меняет случайность остальной модели.
- **Что видит условие.** Событие — формула ГМ, поэтому может читать и истинные счета (раздел 07, п. 5.3). Например,
  «если настоящий дефицит больше 8%, а опубликованный меньше 4%, через полгода журналисты находят расхождение».
- **Режим `ask_gm`.** Сработавшее событие ждёт в панели ГМ. ГМ решает до начала следующего хода. Если не решил, событие
  пропускается и снова проверяется по условию.
- **Пределы.** Событие делает только то, что разрешено шокам и разовым операциям, с теми же классами `edit` (раздел 07, п. 6.1).
- **Цепочки (v1).** Событие ставит метку, другое проверяет её; задержка `after: N` тиков; выбор варианта ГМ из нескольких.

Рейтинговая служба, международный кредитор и ИИ-страны уже реагируют сами по своим правилам (п. 8). События нужны для того,
чего правил нет: политики, общественной реакции, решений других государств.

## 7. Новости (ядро)

Правки и шоки ГМ игрокам не показываются (раздел 07, п. 8). Новость — единственный способ сказать о них.

```yaml
news:
  audience: all                 # all / country / role / список игроков
  when: start                   # start / end / номер тика
  text: {ru: "...", en: "..."}
  reveal: [gov_deficit_true]    # необязательно: открыть игрокам истинную цифру (раздел 06, п. 7)
```

- **Текст на ИИ-агентов не действует.** Если новость должна напугать вкладчиков, ГМ добавляет к ней шок `news_b`.
  Шаблоны так и устроены. Поэтому новость может быть ложной (слух), а шок может пройти молча.
- **Последствия видны и без новостей.** Цена нефти — рыночные данные, банкротства и решения ЦБ — публичные новости
  (раздел 06, п. 7). Игроки видят, что нефть подорожала, но не видят, что это шок ГМ.
- Новости приходят в брифинг хода (раздел 02, п. 2), а при экстренном полуходе — сразу (раздел 02, п. 4).
- Разные игроки могут получить разные новости: условия кредита международного кредитора узнаёт только Минфин страны.

## 8. Решения за ИИ-участников мира (ядро)

| Участник | По умолчанию | Что решает ГМ |
| --- | --- | --- |
| ИИ-страны (раздел 03, п. 10) | цикл AR(1), правило Тейлора своего ЦБ | шоки выпуска, пошлины, санкции, ставки, дефолт ИИ-страны |
| Международный кредитор `IFL` (раздел 03, п. 8.5) | ИИ-правило | программа кредита: сумма, транши, ставка, условия; выдача транша; прощение невыполненного условия |
| Рейтинговая служба | модуль по официальным данным | ставит рейтинг событием, дальше модуль считает от него |
| Мировые рынки сырья (раздел 05, п. 4) | добыча и спрос ИИ-стран | шоки добычи, спроса и мировых запасов |
| Мировые инвесторы | `global_risk_appetite = 1` | рычаг ГМ (раздел 03, п. 10) |
| Роли без игрока | ИИ-правило эпохи | заменить формулу правила или выключить его (раздел 03, п. 13) |
| Реструктуризация госдолга | — | размер списания после переговоров в ролевой части (раздел 03, п. 8.5) |

**Программа международного кредитора.** Кредит выдаётся траншами. Перед каждым траншем проверяются условия по официальным
данным, как в программах МВФ с ежеквартальными пересмотрами.

```yaml
program: ifl_north_2032
borrower: {country: north, role: finance_ministry}
amount: 30e9
currency: usd
rate: "world_rate + 0.03"
tranches: {count: 8, every_ticks: 3}
conditions:                       # формулы по официальным данным
  - "deficit_gdp_official <= 0.04"
  - "cb_gov_financing == 0"
on_fail: suspend                  # suspend — транш не выдаётся; ask_gm — ГМ решает, простить ли
```

Выдача транша — `issue(IFL, GOV, ROW)` и зачисление валюты на счёт казначейства (раздел 01, п. 2.1). Если программа
сорвалась, а рынок закрыт, стране остаются только резервы, печатный станок или дефолт.

## 9. Действия с приказами игроков (ядро)

Ролевая часть иногда должна остановить решение игрока: парламент не принял закон, суд отменил налог. Для этого у ГМ три действия.

| Действие | Что происходит |
| --- | --- |
| Отклонить приказ | приказ не исполняется; постоянное распоряжение приостанавливается |
| Отложить приказ | приказ вступает в силу в указанный тик |
| Открыто сменить рычаг | ГМ ставит рычагу игрока новое значение, дальше игрок снова управляет им сам |

Эти действия **видны игроку** вместе с причиной, которую пишет ГМ. Скрыть их нельзя: игрок увидел бы, что его приказ
не исполнился, и не понял бы почему. Остальные действия ГМ скрыты (раздел 07, п. 8).

## 10. Радар рисков и пробный прогон (ядро)

### 10.1. Радар рисков

Радар — панель ранних сигналов, которую видит только ГМ. Каждый сигнал — формула по истинным счетам с порогом.
Рядом показано официальное значение, поэтому ГМ видит и те случаи, когда игроки не замечают проблему из-за плохой
статистики. Сигналы лежат в данных, ГМ добавляет свои.

| Сигнал | Порог по умолчанию | Почему такой |
| --- | --- | --- |
| Разрыв кредита к ВВП от тренда (односторонний фильтр Ходрика–Прескотта, как у BIS) | 2 п.п. — внимание, 10 п.п. — тревога | по Базелю III контрциклический буфер капитала включается при разрыве 2 п.п. и доходит до максимума 2,5% при 10 п.п. (BCBS 2010) |
| Резервы ЦБ к внешнему долгу со сроком до года | меньше 1 | правило Гринспена–Гидотти (IMF 2011) |
| Резервы ЦБ в месяцах импорта | меньше 3 | традиционная норма МВФ (IMF 2011) |
| Капитал банка | ниже `car_min + car_buffer` | ниже этого банк режет кредит (раздел 03, п. 5.3) |
| Проверка заражения | крах банка роняет хотя бы ещё один банк | см. ниже |
| Мировые запасы сырья | ниже половины нормы `z_ref` | запасы перестают гасить шоки, и цена может прыгнуть в разы (раздел 05, п. 4) |
| Искажение статистики | показывается всегда | вероятность раскрытия за тик (раздел 06, п. 6) |
| Рост кредита, цены жилья, реальный курс | в верхних 10% собственной истории страны | у этих показателей нет общей нормы; порог по процентилю своей истории — метод Kaminsky, Lizondo, Reinhart (1998) |

**Проверка заражения.** Каждый тик для каждого банка на копии балансов считается: что будет, если этот банк сейчас обанкротится.
Его межбанковские долги гасятся тем же клирингом Eisenberg–Noe, что и в партии (раздел 05, п. 11.4), с потерями `bank_bankruptcy_cost`.
Радар показывает, сколько банков упадёт следом и какая доля вкладов окажется в них. Это быстрее полного прогона, потому что
считаются только межбанковские требования, как в работе Furfine (2003).

Так ГМ заранее видит банк, крах которого станет системным кризисом, и может решить: дать кризису случиться, предупредить игроков
новостью или ослабить связи между банками до старта партии.

### 10.2. Пробный прогон

Перед запуском шока ГМ может посмотреть его эффект:

- копия мира прогоняется на `preview_ticks` тиков (по умолчанию 24) дважды: с шоком и без него;
- оба прогона берут одно зерно, поэтому случайности в них одинаковые, и разница показывает эффект шока, а не шум;
- игроки в прогоне ничего нового не приказывают, действуют только их постоянные распоряжения и ИИ-правила;
- прогон не влияет на партию и не виден игрокам (раздел 02, п. 8).

При целях раздела 02, п. 9 два прогона по 24 тика для 10 стран занимают около 4 минут. Ансамбль из нескольких зёрен
с разбросом эффекта — v1.

## 11. Скрытые цели и туман войны (ядро — цели и настройки, v1 — очки)

### 11.1. Скрытые цели

```yaml
goal: cb_inflation
role: central_bank
country: north
text: {ru: "Инфляция к концу партии ниже 5%, без дефолта"}
check: "cpi_yoy_true <= 0.05 and not gov_default"
when: end                 # end; every_year — v1
data: true                # true — по истинным данным; official — по официальным
```

- Игрок видит только свои цели, ГМ — все.
- Цели ролей одной страны могут противоречить друг другу, как в жизни: ЦБ отвечает за инфляцию, Минфин — за долг,
  правительство — за рост и доходы бедных децилей. В пакете эпохи лежат шаблоны целей по ролям.
- Цели проверяются в разборе партии (раздел 06, п. 7). По умолчанию — по истинным данным, чтобы нельзя было выиграть
  ложной статистикой. Для партии про фальсификацию ГМ может проверять цель по официальным данным.
- Очки, рейтинг игроков и проверка целей по ходу партии — v1.

### 11.2. Туман войны

Туман войны — это набор значений из разделов 02 и 06, собранный в готовые варианты. ГМ выбирает вариант и меняет любое
значение отдельно.

| Настройка | Прозрачно | Обычно (по умолчанию) | Густой туман |
| --- | --- | --- | --- |
| Задержка и ошибки статистики (раздел 06, пп. 4 и 5) | вдвое меньше | как в разделе 06 | вдвое больше |
| Ведомственные данные (раздел 06, п. 7) | всем ролям страны | своей роли | своей роли с задержкой в тик |
| Статистика других стран | вся официальная | ключевые официальные показатели | только рыночные данные и новости |
| Прогоны «что если» для игроков (раздел 02, п. 8) | включены | выключены | выключены |

## 12. История страны в разгоне (ядро)

ГМ может вставить в разгон прошлые события (раздел 08, п. 5.3). Историческое событие — шок, разовая операция, шаблон
или **принудительная политика**: формула ИИ-роли заменяется на срок (`op: formula`, п. 2.1). Даты событий — до старта
партии, тики у них отрицательные.

| История | Как задаётся | Что страна помнит на старте |
| --- | --- | --- |
| Гиперинфляция 8 лет назад | правила ИИ-Минфина и ИИ-ЦБ заменены на 24 тика: дефицит 10% ВВП покрывается деньгами ЦБ | низкое доверие к ЦБ `ω`, валюта в сбережениях |
| Банковский кризис 3 года назад | шок ожиданий цен жилья вниз и «дыра» в балансах двух банков | банки осторожны (память о дефолтах `pd_memory`), часть вкладов осталась в госбанках и наличных |
| Дефолт 5 лет назад | ИИ-правительство объявляет дефолт | прошлый дефолт в оценке риска (`b_hist`), рейтинг ниже |
| Девальвация 2 года назад | ИИ-ЦБ отпускает фиксированный курс при атаке | валютные долги выросли, инфляция ещё не ушла |
| Война 10 лет назад | разрушение капитала и жилья в регионах, мобилизация, эмиграция | меньше капитала и населения, новое оборудование рядом со старым |

- **Память возникает сама**, через обычные механизмы: доверие к ЦБ, портфель домохозяйств, память банков, доверие
  к статистике. Ручку `inflation_memory` (раздел 08, п. 2.2) при этом ставить не обязательно. Если ГМ задал и её,
  и гиперинфляцию в истории, отчёт о старте предупреждает о двойном учёте.
- **Подгонка к целям и история.** Подгонка (раздел 08, п. 5.2) идёт только до первого исторического события, потом
  экономика идёт сама. Иначе подгонка гасила бы последствия истории: например, тянула бы инфляцию к цели посреди гиперинфляции.
- **Длина разгона** с историей: `max(burnin_years, окно подгонки + возраст первого события)`, где окно подгонки —
  `burnin_steer_share · burnin_years`. При событии 8 лет назад и окне 3 года разгон длится 11 лет, около 11 минут при целях
  раздела 02, п. 9.
- Отчёт о старте (раздел 08, п. 6) помечает цели, которые не достигнуты из-за истории: «вне допуска: последствия
  гиперинфляции 8 лет назад». ГМ принимает это или меняет ручки.

## 13. Сценарии кризисов (ядро)

Сценарий кризиса — набор стартовых условий и шаблонов по первопричине. Те же сценарии раздел 10 прогоняет как исторические
стресс-тесты: тест пройден, если сам возник нужный порядок событий.

| Сценарий | Что задаёт ГМ | Что должно возникнуть само |
| --- | --- | --- |
| Великая депрессия (1929) | золотой стандарт, нет страхования вкладов, биржевой пузырь на старте (раздел 08, п. 8), затем слух о крупных банках | обвал биржи → паника вкладчиков → сжатие денег → дефляция, банкротства, безработица в разы выше обычной |
| Нефтяной шок (1973) | эмбарго на 7,5% мировой добычи; сильная индексация зарплат и мягкий ЦБ | инфляция и безработица растут одновременно |
| Гиперинфляция | не шок: ИИ-Минфин или игрок покрывает дефицит деньгами ЦБ | бегство от денег, долларизация, обесценение налогов (эффект Оливера–Танзи), рост дефицита |
| Азия 1997, Россия 1998 | фиксированный курс, короткие валютные долги на старте; внезапная остановка капитала и падение цен экспорта | атака на валюту, девальвация, разорение заёмщиков и банков; в варианте 1998 года — дефолт по госдолгу |
| Ипотечный кризис (2008) | нарастание мягких стандартов ипотеки за 2–3 года (`ramp`), затем пересмотр ожиданий цен жилья | цены жилья падают, ипотеки уходят в дефолт, кредит сжимается, ставка ЦБ упирается в нижнюю границу |
| Дефицит в плановой экономике | дополнение «плановая экономика», рост денежных доходов, мягкий бюджет | очереди, вынужденные сбережения, наценка чёрного рынка растёт |
| Пандемия (2020) | шаблон «пандемия» | спад без обвала выпуска на 50% (раздел 04, п. 3), рост сбережений, сбои поставок |
| Санкции и война | шаблоны «санкции» и «война» | нехватка импортных критических входов, обход санкций, падение курса, инфляция |

## 14. Связь с другими разделами

- Шоки — временные правки данных из раздела 07, п. 8. Они применяются на шаге 0 тика (раздел 02, п. 5).
- Разовые операции — базовые операции раздела 01, п. 6, и после них выполняются все проверки раздела 01, п. 10.
- Цели шоков — параметры разделов 03–06 (п. 2.4). Новое слагаемое `uncert_gm` входит в правило инвестиций раздела 03, п. 4.5.
- История страны идёт в разгоне раздела 08, п. 5 и меняет его длину и окно подгонки (п. 12).
- Радар читает истинные счета (раздел 01, п. 8) и использует клиринг межбанка раздела 05, п. 11.4.
- Сценарии кризисов (п. 13) — исторические стресс-тесты раздела 10.

## 15. Какие кризисы порождает этот раздел

Сам раздел кризисов не создаёт: он даёт первый толчок, а кризис развивается по правилам разделов 03–05.

| Кризис | Как он связан с инструментами ГМ |
| --- | --- |
| Кризис по первопричине | шок меняет причину, дальше спад, инфляция или паника развиваются сами (п. 1) |
| Политический кризис в экономике | ролевое событие → премия за риск, отток капитала, неопределённость фирм (п. 5.2) |
| Срыв программы международного кредитора | условие не выполнено → транш не выдан → резервы, печатный станок или дефолт (п. 8) |
| Системный кризис из-за одного банка | при малом числе банков крах крупного валит остальных; радар показывает это заранее (п. 10.1) |
| Ложный кризис от слишком сильного шока | не кризис, а ошибка настройки; от неё защищают пробный прогон, реалистичные зоны и обрезка по диапазону (пп. 2.3 и 10.2) |
| Наследие прошлого | история страны в разгоне (п. 12) |

- [ ] Формы шоков (предлагаю: в ядре пять форм — разово, ступенька, затухание, нарастание, постоянно, их можно соединять

- [ ] Что можно шоковать (предлагаю: любые параметры, слоты формул и переключатели `live`, кроме рычагов игроков и самих цифр

- [ ] Действия с приказами игроков (предлагаю: ГМ может отклонить, отложить или открыто сменить рычаг, и игрок видит это

- [ ] Режим событий (предлагаю: события из библиотеки по умолчанию ждут решения ГМ до следующего хода, свои события ГМ
