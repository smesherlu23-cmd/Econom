# Econom

Пошаговый движок экономики государства для ролевых игр, политиков и экономистов.
Игроки управляют экономикой вымышленных государств (правительство, Минфин, ЦБ, министерства),
ГМ создаёт кризисы и переводит ролевые события в экономические шоки.

- Эпохи: XX и XXI век, каждая эпоха — пакет данных.
- Ход: месяц, квартал или год (выбирается при настройке партии), базовый тик модели — 1 месяц.
- Ядро: агентная модель с согласованностью запасов и потоков (stock-flow consistent).
- Все правила и числа лежат в данных и меняются без правки кода.

## Документы

- [Концепция](https://claude.ai/artifact/N9ojGdRrD7cF8rLoqnDP4o) — цели, архитектура, принятые решения.
- [Спецификация модели](docs/spec/README.md) — формулы, балансы и правила, по которым пишется код.

## Как ведётся разработка

1. Спецификация модуля пишется и согласуется в `docs/spec/`.
2. По спецификации пишутся тесты: балансы сходятся, модель воспроизводит известные закономерности.
3. Код пишется до зелёных тестов, каждое изменение — отдельный pull request.
